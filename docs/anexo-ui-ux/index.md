# Anexo: diseño UI/UX para videojuegos

La interfaz es lo que se interpone entre el jugador y el juego: menús, barras de vida, inventarios, mapas. Estos apuntes no forman parte de los resultados de aprendizaje del módulo, pero te resultarán útiles porque el diseño de interfaces se apoya en lo que trabajas en él: composición, jerarquía visual, tipografía y coherencia con el estilo del juego.

!!! concept "Relación con el concept"
    Una interfaz también es arte del juego y debe salir de la misma [biblia de arte](../concept/biblia-de-arte.md): la misma [paleta](../concept/color.md), el mismo [estilo](../concept/estilos-artisticos.md) y el mismo lenguaje de formas que los personajes y el mundo.
