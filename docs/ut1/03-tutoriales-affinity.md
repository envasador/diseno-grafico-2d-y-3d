# UT1 Tutoriales de Affinity

Hay cosas de un programa que se entienden mejor viéndolas que leyéndolas, y dónde está cada botón es la primera de la lista. Para eso tienes esta serie de tutoriales de **CG con Ana Lucía**, en español y hecha con **la misma versión de Affinity que usamos en clase** (la gratuita de Canva). Lo ideal es verlos **con Affinity abierto al lado** y repetir cada paso a la vez que ella; mirarlos como quien ve una serie no deja mucho.

El resto de la lista es **de consulta**, para cuando lo necesites:

- **[Autotrazado, relleno en malla, eliminar fondo, nuevos filtros y ajustes](https://www.youtube.com/watch?v=N4psqVI5abE)** (21 min). El autotrazado convierte una imagen en vectores y te puede venir bien para pasar un boceto escaneado a vector. Eso sí, revisa siempre el resultado, porque el programa traza exactamente lo que ve, borrones y manchas de café incluidos.
- **[Diseña patrones geométricos automáticos](https://www.youtube.com/watch?v=yroyPsfrd2Q)** (32 min) y **[Cómo usar símbolos para crear patrones](https://www.youtube.com/watch?v=vtBIURIALO4)** (30 min). Muy útiles para texturas, fondos y piezas que se repiten. Guárdalos para la UT2, cuando trabajes con tiles.
- **[Cómo rellenar el contenido o expandir el fondo de una imagen automáticamente](https://www.youtube.com/watch?v=4mGLx6c7F_0)** (11 min). Usa las funciones de **Canva IA**, que necesitan una cuenta de Canva Pro. No las vas a necesitar en este módulo.
- **Las novedades de cada actualización:** [3.1](https://www.youtube.com/watch?v=c3SB3zK-HD4) (17 min), [3.2](https://www.youtube.com/watch?v=ZRsjYI7eqI4) (16 min) y [3.3](https://www.youtube.com/watch?v=vZa36qvz7Dw) (23 min). Si un tutorial (este u otro) enseña un botón que tú no encuentras, lo más probable es que haya cambiado en alguna actualización. Aquí lo puedes comprobar.
